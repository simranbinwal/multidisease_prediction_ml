
# 🏥 Multi-Disease Prediction System

A Machine Learning-based web application that predicts **Heart Disease Risk** and **Mental Stress Level** using health-related parameters. The application provides a user-friendly interface, real-time predictions, and downloadable PDF reports.

---

## 📌 Project Overview

The Multi-Disease Prediction System is designed to assist users in obtaining preliminary health assessments through machine learning models. Users can enter their health information through a web interface, and the system analyzes the data to provide disease risk predictions.

The project integrates:

* Machine Learning
* Flask Web Framework
* HTML, CSS, and JavaScript
* PDF Report Generation

## 🔄 System Workflow

1. User enters health details.
2. Frontend sends data to Flask backend.
3. Backend processes data.
4. Trained Machine Learning model performs prediction.
5. Result is returned and displayed.
6. User can download a PDF report.

## ❤️ Heart Disease Prediction Parameters

* Age
* Sex
* Chest Pain Type
* Resting Blood Pressure
* Cholesterol
* Maximum Heart Rate

### Output

* High Risk
* Low Risk
* Prediction Probability (%)

## 🚀 Installation

### Clone Repository

```bash
git clone https://github.com/yourusername/multi-disease-prediction.git
cd multi-disease-prediction
```

### Install Dependencies

```bash
pip install -r requirements.txt
```

### Train Models

```bash
python train_heart_model.py
python train_stress_model.py
```

### Run Application

```bash
python app.py
```

Open:

```text
http://127.0.0.1:5001
```
